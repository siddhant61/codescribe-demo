A practical starting point

Ask a smaller, better-grounded question.

  1. Choose a functional area

    Start with the cluster closest to your task. Read its report alongside the corresponding JSON.

  2. Keep the source in view

    Use the artifact to find relevant components, then inspect those files in the code revision you are actually working on.

  3. Provide focused context

    Share only the relevant, permitted material with your coding assistant. Ask it to distinguish source-backed observations from inferences.

  4. Review the result

    Check references, test proposed changes and revise the explanation when it conflicts with the source.
